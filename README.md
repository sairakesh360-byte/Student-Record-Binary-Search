# Student Record Lookup System

## About the Project

This project is a Student Record Lookup System designed to efficiently search student records using Binary Search.

The system simulates 10,000 student records with unique roll numbers.

## Features

- Generates 10,000 student records
- Sorts records by roll number
- Uses Binary Search for efficient lookup
- Supports multiple roll-number searches
- Displays whether a student is found or not found
- Counts operations for every search
- Calculates total operations
- Calculates average operations
- Displays minimum and maximum operations

## Algorithm

### Binary Search

Binary Search works on sorted data by repeatedly dividing the search space into half.

### Time Complexity

- Best Case: O(1)
- Average Case: O(log n)
- Worst Case: O(log n)
- Space Complexity: O(1)

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Run the Python file.
4. Enter the number of roll numbers you want to search.
5. Enter the roll numbers when prompted.
6. Enter `0` to exit.

## Example

The system can search multiple roll numbers and display:

- Student name
- Found / Not Found
- Number of Binary Search operations
- Total operations
- Average operations
- Minimum operations
- Maximum operations
